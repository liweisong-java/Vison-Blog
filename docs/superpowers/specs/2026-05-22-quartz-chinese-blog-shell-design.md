# Quartz 中文博客壳改造设计

## 背景

当前公开站已经切换到 Quartz 承担首页与文章页展示，但视觉和交互仍保留较强的文档站/知识库风格：

- 首页仍是“首页笔记 + 工具侧栏 + 文档流列表”的组合。
- 文章页左侧常驻搜索、阅读模式，右侧常驻目录，阅读压迫感较强。
- 中文长标题被强制单行省略，更像工具列表，不像中文博客。

这不是思源与 Quartz 数据融合失败，而是公开展示壳不适合当前博客定位。

## 目标

- 让公开站更像中文个人博客，而不是知识库。
- 保留现有思源同步与 Quartz 内容构建链路，不改内容源与部署方式。
- 仅重做 Quartz 公开页的布局组件与样式层。

## 方案

### 首页

- 去掉首页左侧常驻工具栏，改为更轻的顶部区。
- 首页不再展示明显的“首页正文卡片感”，只保留简短博客引子。
- 首页文章列表改成单栏中文博客流，标题允许两行自然换行。
- 列表日期弱化，卡片从“工具列表”改成“文章条目”。

### 文章页

- 左侧工具区改成更轻的阅读辅助区，不再占据强视觉权重。
- 右侧目录只在桌面端保留轻量表现，移动端默认隐藏或折叠。
- 标题、标签、正文保持清晰，但去掉明显文档站味道。

### 风格

- 缩小外壳组件存在感，让正文和标题成为主角。
- 调整中文标题换行、间距、边框、卡片圆角与留白。
- 让 Quartz 公开站在气质上更接近现有 Astro 的关于我/归档页。

## 影响范围

- `apps/quartz/quartz.layout.ts`
- `apps/quartz/quartz/components/HomeFeed.tsx`
- `apps/quartz/quartz/components/styles/homeFeed.scss`
- `apps/quartz/quartz/styles/custom.scss`
- 可能补充少量 Quartz 组件测试

## 非目标

- 不切回 Astro 作为公开站主渲染器。
- 不修改思源同步、服务器发布、组合部署逻辑。
- 不在本轮重写文章正文 Markdown 转换逻辑。

## 验收标准

- 首页视觉上不再像知识库首页。
- 首页文章标题允许两行内自然换行，不再统一单行截断。
- 文章页阅读区明显比当前更轻、更聚焦内容。
- `pnpm test`、`pnpm check`、`pnpm build` 继续通过。
